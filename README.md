Pizza World & Fast Food - front end

Open index.html, or run: npx serve .

Pages: index.html, menu.html, deals.html, checkout.html, contact.html

Edit menu and prices: js/data.js
Edit WhatsApp order number, hours, delivery fee: CONFIG at the top of js/data.js

Product photos: save a photo as images/<name>.jpg using the exact file names printed by "node tools/photos.js", then run that command again. Items without a photo show a drawn illustration.
